# Air cargo project
This project focuses on managing and analyzing airline operations data, including passengers, flight routes, ticket sales, customer information, and revenue generation.
The solution demonstrates the application of core and advanced SQL concepts such as database design, ER modeling, joins, views, indexes, stored procedures, stored functions, window functions, cursors, execution plans, and performance optimization. The project uses data from customer.csv, passengers_on_flights.csv, ticket_details.csv, and routes.csv to generate business insights for an airline company. turn2search5

Key Features
1. Designed and implemented a relational airline database model with anER Diagram.
2. Analyzed passenger travel patterns across multiple flight routes.
3. Calculated revenue, ticket sales, and customer travel statistics from airline operations data.
4. Created stored procedures and functions for business logic automation.
5. Used window functions, ROLLUP, views, and cursors for advanced SQL analysis.
6. Improved query performance using indexing and execution plan analysis.
7. Applied database security concepts through user creation and privilege management.
